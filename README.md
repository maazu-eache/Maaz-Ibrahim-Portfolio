# Maaz Ibrahim — Full Stack Developer Portfolio

Professional portfolio website for **Maaz Ibrahim**, Full Stack Developer with 3+ years of experience building scalable, responsive web and mobile applications with clean, efficient code and a strong focus on user experience.

## 🚀 Tech Stack

- **Frontend**: React 19, Modern CSS (Vanilla Design System), Responsive Layouts, Fluid Typography
- **Icons**: Lucide React
- **Build Tool**: Vite
- **Deployment**: Vercel

## 💼 Core Skills Featured

- **Full-Stack**: React, React Native, Node.js, Express.js, REST APIs, Component-Based Architecture
- **UI & Styling**: HTML5, Modern CSS, Bootstrap, Responsive & Accessible Design
- **State & Data**: State Management, API Integration, Client-Side Form Validation
- **Backend & Database**: Server-Side Logic, MongoDB, Schema Design, CRUD Operations
- **Security & Auth**: JWT-based Authentication, Role-Based Access Control (RBAC)
- **Payment Flow**: PayPal & Stripe Integration with Status Handling
- **Engineering Rigor**: Problem Solving, Debugging, Performance Optimization, Clean Code Practices

## 📁 Key Projects

- **Telework Bridge**: Freelance marketplace platform connecting freelancers and clients with role-based flows and payment handling.
- **XLIM-CONNECT**: Enterprise application for order, user, and inventory management with granular RBAC security.
- **MOMMAS KITCHEN**: Cross-platform web and mobile food ordering app with component refactoring and performance tuning.
- **JEWEL APP (AURUM)**: Merchant and user management fintech app for jewelry chit schemes and investment plans.

## 🛠️ Local Development

```bash
# Install dependencies
npm install

# Start Vite dev server
npm run dev

# Production build
npm run build
```
